## 🛠️ Troubleshooting

- **Overlay does not appear** — make sure VRChat is running and you are in a world (not the menu). Try pressing `Tab` or `Insert`. Run the helper as administrator if needed.
- **Game crashes on launch** — verify game files via Steam, then reapply the helper. Disable other overlays (Discord, Steam) temporarily.
- **Hotkeys not working** — check for conflicts with other software. Change `menu_hotkey` in the config file.
- **Performance drops** — reduce overlay update rate in settings or disable heavy modules.
